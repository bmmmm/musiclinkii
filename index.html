How it works

Everything runs in your browser — there is no backend. The pasted link is parsed, track or album metadata is fetched from keyless public endpoints (iTunes, Deezer, YouTube and Spotify oEmbed, MusicBrainz), and links for the other platforms are built from each service’s own URL scheme. Exact matches are marked; everything else is an honest search link. No link at hand? Type “Artist - Title”, open the artist / title / album form, or scan a vinyl cover. Cover OCR and the optional artwork comparison run locally; only recognized text is sent in catalog searches. The selected image and its visual vector are never uploaded. No analytics, no cookies, no tracking.
